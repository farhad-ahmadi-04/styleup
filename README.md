# StyleUp

StyleUp is an e-commerce application built with a customer storefront and an admin area. Supabase is used as the backend for the project.

## Features

- Customer-facing product browsing and shopping experience
- Admin-facing tools for managing the store
- Supabase backend integration

## Getting Started

1. Clone this repository.
2. Install dependencies using the package manager configured for the project.
3. Configure the required Supabase environment variables. Check the application configuration or source code for their exact names.
4. Start the application using the development script defined in `package.json`.

Do not commit Supabase credentials or other secrets to the repository.
